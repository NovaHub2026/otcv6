## 2. The finding that matters most

**An aliased engine snapshot on a production route passed the INV-010 guard
(a1-01, critical).** Cycle Audit 8 closed a finding of this exact shape by
making `labSurface.test.ts` scan production sources for `snapshot`,
`snapshotEngine()` spread and the word `cursors` near a return, and recorded
the guard as "about the value". It was still about words: the auditor added
`GET /markets/:id/support` returning `{ id, state }` with
`state = hosted.snapshotEngine()`, ran the whole unit project green, booted the
service and read all seven keystream cursors and the whole latent state off
the production composition. The guard that closes it reads the _response_:
`productionResponses.test.ts` boots a real production venue in-process,
enumerates every GET route from Nest's own route metadata — so a route added
tomorrow is enumerated tomorrow — calls each with a live asset id, and walks
the JSON for a cursor-formatted string or a snapshot-only key. The same plant
fails it with twelve leaks named; the source scan stays as the second layer.

Two things follow. A guard recorded as closed by an audit is not thereby
closed — the next audit re-plants it, and this one found the previous audit's
closure to be a narrower guard than its record said. And the structural half
of the finding stands: `VenueService.hostedMarket()` is public and hands out
an object whose `snapshotEngine()` a production controller may call. That is
a phase-sized change to the venue's surface and goes to the improvement
report, not into a fix commit.

## 3. What the audit found about the cycle's own approvals

The PH-25 merge `7f03abe` was **red on both hosted gates** — on a unit test's
hosted timing, and on the meta-audit because the merged state documents
already failed `stateConsistency.test.ts`: the approval was committed with the
state guard red, after the gate had run on an earlier tree (a7-01, a7-02).
`CURRENT_STATE.md` said "green on both". The record now says what happened,
and `npm run state:check` — the two state guards, ten seconds — is written
into CLAUDE.md §5 as the step before every approval commit. Hosted CI on the
PH-27 merge `e8ed2ae` is recorded in `CURRENT_STATE.md` § "Hosted CI,
honestly" when it lands; the Quality Gate fix is in that commit.

The heavy statistical suites sampled five assets over six archetypes, so one
archetype per suite — and `alt-crypto` for every battery and tie check — was
never measured at any gate (a2-01). The sample is six now, one per populated
archetype, and a sample that cannot reach every stratum is refused by name;
the cost is measured at the next gate. Seventeen of thirty assets remain
unmeasured by any heavy suite per gate; the whole-catalogue records the
auditor proposed are carried to the improvement report with their cost.
