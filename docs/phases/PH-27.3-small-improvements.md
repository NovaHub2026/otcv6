no price path. Each is either done with a guard, or measured and sent to the
report as a phase.

## 4. What was closed, and what was measured and carried

| Candidate                                                  | Outcome                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assessRealism` blocks the event loop (PH-24 §9, PH-24.19) | **closed.** The fifteen metrics are one generator; `assessRealism` drains it as before, `assessRealismAsync` turns the loop before each step, and `/lab/markets/:id/quality` uses the latter. `realism.test.ts` asserts identical metrics and counts loop turns with a self-rescheduling immediate (0 during the synchronous form, ≥ 15 during the asynchronous); a plant that removed the yield failed it by name.                         |
| The browser does not read `resumesAt` (PH-25.1 finding b)  | **closed** for the preview chart: a told gap's bounds are read off the frame's own fields (`holeOf`, `holeOf.test.ts`) and the status names the sequences not served — "hueco avisado por el motor: secuencias A–B no servidas" — rather than "a gap". A join the builder found broken on its own names no bounds, honestly. The main chart's stream never asks to be told (it starts over), so there is nothing there to bound; report §2. |
| The panel opens one connection per asset (Issue #16)       | **carried**: the multiplexed endpoint exists (PH-22.2) and adopting it is a rewrite of `marketStream.ts` and both charts' resume logic, a subphase or more; report §2.                                                                                                                                                                                                                                                                      |
| `aggregational-gaussianity` aggregates in ticks (PH-24 §9) | **carried**: re-expressing it in time changes the metric's band, which is a calibration decision the report classes (§1.2).                                                                                                                                                                                                                                                                                                                 |
| Six spawned-service test files carry the same boot helper  | **carried**: the copies differ in secret, ports, backfill and what they assert about boot; a shared helper is a refactor of six statistical files, each six minutes to re-verify, and belongs to a phase that touches them anyway.                                                                                                                                                                                                          |
