## 1. Objective

The next four items of the Lab inventory of 2026-09-03, all about what a
session **leaves behind** and what it can say about itself:

1. **The session survives the process** (§78). `LabSession` lives in memory and
   a restart empties it — a record that is not there in the morning is not an
   audit record. It is written to the Lab's own state directory as it grows and
   read back at boot; the screen can export it.
2. **§70 over positions' outcomes.** The closes diagnostic reads the operator's
   distances; a second reading takes the positions — how many won, by which
   preset — and says when a session is _siempre gana_.
3. **The boundary-tick indicator** (ADR-0017). When an applied close's candle
   ends on a tick that lands exactly on the boundary, the chart's candle and the
   settlement price differ by that tick; the Lab knows and should say so on the
   outcome line rather than let an operator find it on the chart.
4. **Trend strength as what it is**: net displacement over a window, on the
   Mercado tab, with the sentence that the engine has no trend mechanism.

## 2. Persistence, and what it is not

An append-only JSON-lines file under `OTC_STATE_DIR/lab/session.jsonl` — one
line per event or action, the two streams distinguishable by a `stream` field
in the file only (the class keeps its two arrays; a reader that merges them has
chosen to). Written on every record, read once at boot, exported through
`GET /lab/session/export` as the same file. Nothing here touches a market
record: the Lab's session is about the Lab.

## 3. Acceptance criteria

1. A Lab restarted with the same state directory shows the previous session's
   actions and events; a fresh directory shows none.
2. `GET /lab/session/export` returns the file; the screen offers it.
3. `GET /lab/session/positions` reports settled positions by outcome and by
   preset, with the count a verdict rests on, and calls ten wins in ten
   _one-sided_.
4. An applied close whose end falls on a boundary tick is marked on the
   outcome line — reproduced by constructing one on a stepped clock.
5. Mercado shows net displacement over the last minute and five minutes.
6. Guards, plants, browser flow for 1–3, targeted gate.

## 4. Scope

- `apps/api/src/lab/session.ts` — the store; `lab.module.ts`, `lab.main.ts`
- `apps/api/src/lab/lab.controller.ts` — `session/export`, `session/positions`,
  the boundary flag on `control`
- `apps/web/src/app/lab/{Sesion,Cierre,Mercado}.tsx`, `lib/es.ts`
- tests beside each

**Excluded:** several assets armed at once (PH-24.9), replay and snapshot
(§74–§77), large runs as jobs (§67).
