## 1. Objective

Every "what the phase leaves open" section from PH-20 onward, every open
GitHub Issue, and the architecture documents' own admissions, read against
the tree as it is — and each item marked **still open**, **closed by** (the
closing phase or commit named, with the guard that holds it), or **carried**
to PH-27.5's report. A record that says "open" about something a later phase
closed sends the next reader to rebuild what exists.

## 2. Sources

- `docs/phases/PH-20` §5, `PH-21` §8, `PH-22` §8, `PH-23` §10, `PH-24` §9,
  `PH-25` §7.
- GitHub Issues #2–#22 (open), each re-checked against the tree; those the
  tree closes are closed with the commit named; the two that are the Human
  Owner's (#3, #14) are left as they are.
- `docs/architecture/*.md` admissions ("not yet", "unmeasured").
- `CLAUDE.md` §5's numbers, re-measured from the PH-25 gate.

## 3. Acceptance

1. Each open-items section carries a dated line per item with one of the
   three verdicts and, for **closed by**, the guard that holds it.
2. No Issue remains open that the tree closes; none is closed by narrative.
3. The architecture documents mention the Lab and the served-record
   instrument where their headers say absence means nonexistence.
