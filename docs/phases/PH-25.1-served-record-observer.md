# PH-25.1 — An Observer That Builds A Dataset From The Served Record Alone

Type: SUBPHASE TECHNICAL DOCUMENT
Identifier: PH-25.1
Parent: [PH-25](PH-25-production-record-battery.md)
Status: ACTIVE
Created: 2026-09-05

---

## 1. Objective

Give `packages/lab` a source it has never had: the ticks as a browser would
hold them, read over `GET /markets/:id/stream` from a running `apps/api`, and
nothing else — no engine, no snapshot, no state directory.

## 2. What is built

**`servedRecord(baseUrl, assetId, options)`** in `packages/lab` — an SSE
client for Node that connects, resumes from a sequence, reads until a target
sequence or instant, keeps every `tick` frame, records every `gap` and `close`
frame it is told, and returns a `TickSource` the existing `buildObserverDataset`
consumes unchanged. Two things it must be, and both are asserted against a
spawned service:

1. **Faithful.** Two observers on two connections produce byte-identical
   datasets (INV-002), and a dataset read after a deliberate restart of the
   service — checkpoint, SIGKILL, resume — is the same sequence, with the seam
   the record declares where the record declares it (INV-008).
2. **Honest about what it did not see.** A `gap` frame is not a tick; a
   resume the server refuses is not a continuation. The source reports both,
   and a dataset built across either says so rather than closing the hole.

**Nothing the observer cannot read.** The client uses the public read surface
only; `labSurface.test.ts`'s scan is extended so that nothing under
`packages/lab/src/served/` imports from `@otc/engine`'s generation code or from
`@otc/runtime`.

## 3. Acceptance criteria

1. A dataset built from the served record of a spawned service equals, tick for
   tick, the dataset built from the same engine in-process for the same span.
2. Two connections, identical datasets.
3. Across a restart, the dataset continues and the seam is where the record
   says.
4. A told gap is recorded, never filled.
5. The observer imports nothing but the public surface; the scan is watched
   failing against a planted engine import.
