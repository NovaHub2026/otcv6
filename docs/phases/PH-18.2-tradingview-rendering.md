## 1. Which TradingView

Two products carry the name and the difference is a Protected Human Decision.

**Lightweight Charts** is Apache-2.0 and needs no agreement; it is what this
subphase uses, pinned at 5.2.1. **The Charting Library** is free of charge and
requires signing a licence, which binds the Human Owner outside the repository
(`GOVERNANCE.md` §5.1) and is not this agent's to accept.

## 2. What the chart library is allowed to decide

Nothing about the data.

The record already holds OHLC bars whose highs and lows are prices the market
**actually visited**, each traceable to the ticks that produced it. So the bridge
between them is a change of units, and `bars.ts` is that bridge: framework-free,
free of the chart library, and unit-tested.

That split is the point. A component that mounts a chart is either visible or
broken; **a bar builder that loses a spike looks fine**. So every decision that
could be silently wrong lives in the tested layer:

- which bucket a tick belongs to;
- whether an open bar may narrow (it may not — a viewer who saw a spike must not
  watch it disappear because a later tick came back);
- whether a replayed tick is folded twice (it is not — a reconnecting stream
  resumes from the client's last sequence and an off-by-one on either side
  replays);
- whose bar the join belongs to.

## 3. The join

History ends at the last flushed bar; the stream starts at the first tick after
the socket opens. They overlap, and the rule is that **the record's bar wins**.

A bucket history already holds was folded from every tick in it. Rebuilding it
from the fragment that arrived after this client connected would draw a
different bar, for the same minute, to this viewer only — INV-002 broken in the
last hop, where nothing downstream could detect it.

## 4. Sub-minute is served live, not from storage

The history tier stores minutes and refuses anything finer, because a stored
one-second bar of last March would be a shape no tick produced. But the
sub-minute view is exactly where an operator judges whether a personality _feels_
right — the arrival rhythm, the bursts, the pauses.

So it is served where it honestly can be: live, from the tick stream, through
PH-8's extreme-preserving reduction, at `/preview/ticks/[assetId]`. PH-8's chart
is not superseded by a candle view; it answers the question the candle view
cannot.

## 5. What this found

**`apps/web` was never typechecked by the gate.** The root `tsc -b` covers the
composite projects and the web app is `noEmit`, outside the reference graph. It
was typechecked only by `next build`, which nothing in the gate runs. So the one
package where a type error is most likely — the one with a UI framework, a chart
library and a network boundary in it — was the one the gate did not read.

`npm run typecheck:web` now runs between `build` and `lint`, and is part of
`npm run gate`.
