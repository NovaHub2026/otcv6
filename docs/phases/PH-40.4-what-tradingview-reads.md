## 1. Objective

Cycle Audit 13's largest carried material (a3-03): the candle item a chart
consumes had no shape in the contract — `candles: 'array'` — so a refuter fed the
history route `[{nonsense:true,logQuantum:'banana'}, 7, null]` and the shape check
passed it, and the conformance suite never requested `/markets/:id/history` at
all. With it, a2-04: a published price did not say how many decimals its
`displayPrice` carries, which is what TradingView's `pricescale` is.

## 2. What TradingView asks for, and what the engine already had

Read from the broker this phase serves: TradingView requests 1, 5, 15 and 30
minutes and maps 60, 120, 240 and 1D; it reads `pricescale`, `minmov` and a
`volume` on every bar.

- **Volume** is `tickCount`, which every stored candle already carries.
- **The two-hour bar is not the engine's.** The broker's backend already builds
  every interval, `2h` included, by aggregating minute bars
  (`INTERVAL_SECONDS` in its simulator), and TradingView itself builds an
  interval from a finer one the datafeed lists. A stored `2h` series would start
  empty on every running deployment and add a timeframe to the divisibility
  chain for nothing a broker lacks. It was the planned title of this subphase and
  it was dropped on reading the broker's code.
- **`pricescale`** is `10 ** displayPrecision`; the precision now travels with
  every price and every candle.

## 3. What is built

| Where                                                           | Change                                                                                                                                                                  |
| --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/client/src/contract.ts`                               | A field may declare `{ items: Shape }`: an array whose every item is held to a shape. `CANDLE` is that shape; `PUBLISHED` gains `displayPrecision`. Contract **3.3.0**. |
| `packages/client/src/shape.ts`, `apps/api/src/contract.test.ts` | Both shape checkers — the client's and the API's own, deliberately independent — hold each item to its shape.                                                           |
| `apps/api/src/market.controller.ts`                             | Every published price and every candle carries `displayPrecision`; null together with the frame when a bar straddles a change of unit.                                  |
| `packages/client/src/conformance.ts`                            | **A stored candle is the ticks it was folded from**: every 1m bar lying wholly inside the ticks the stream handed over is refolded and compared.                        |

## 4. Guards, each watched failing

| Plant                                              | What went red                                                                       |
| -------------------------------------------------- | ----------------------------------------------------------------------------------- |
| the client's shape checker skips an items shape    | `holds every item of a typed array to its shape` — fed Cycle Audit 13's own payload |
| the API's independent checker skips an items shape | `the shape check sees what it is for`                                               |
| candles lose `displayPrecision`                    | `every JSON response has exactly the keys and types the contract names`             |
| published prices lose `displayPrecision`           | the same walk                                                                       |
| the candle conformance check neutralised           | the fault row `a stored candle whose close is not the tick it closed on`            |

**Two guards were blind first, and both for want of input.** The API's JSON walk
built its controller without a candle history, so `/history` answered its listed
404 and the walk skipped it: dropping `displayPrecision` from every candle turned
nothing red. It now runs with a history fed the venue's own ticks, and asserts
that `/history` was read and answered at least one candle. And the new
conformance check passed its own fault as `NOT PROVEN`, because the fake venue's
one bar spanned all sixty ticks and the suite had read forty: the fake now folds
two, and a test asserts the check is _proven_ on a faithful venue, not merely
passed.
