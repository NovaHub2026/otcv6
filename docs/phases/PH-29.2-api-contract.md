## 1. Objective

Turn the venue's routes into a contract a broker can code against: one
document that says what every public route takes and returns, served by the
venue itself, carrying a version that moves when the contract does — and a
guard that fails the build when a route or a response shape changes without
the version.

## 2. What is built

- **`apps/api/src/contract.ts`** — the contract as data: every public read
  route (`/health`, `/markets`, `/markets/:id`, `/catalogue`, `/archetypes`,
  `/markets/:id/history`, `/markets/:id/stream` and `/markets/stream` with
  their frames, `/markets/:id/ticks/:sequence`, `/markets/:id/price`,
  `/markets/:id/proof/:sequence`), its parameters, its response keys with
  types, and its refusals; and `API_VERSION`.
- **`GET /contract`** serves it; `/health` carries `apiVersion`.
- **The guard**, a unit test beside `contract.ts`: the routes the controller declares equal
  the routes the contract names; every route's live response (from a venue
  with a record and an archive) has exactly the keys the contract names, with
  the types it names; and a snapshot of the contract is committed
  (`docs/architecture/API_CONTRACT.md`, generated from the data) so a change
  shows in a diff and the guard fails unless `API_VERSION` moved with it.

## 3. Acceptance criteria

1. `GET /contract` and `docs/architecture/API_CONTRACT.md` agree, byte for
   byte on the generated part.
2. Adding a key to a response, removing a route or changing a type without
   moving `API_VERSION` fails the unit suite by name; moving it passes.
3. The contract names every public GET route the controller declares and no
   other; the write routes are listed as admin with their credential.
4. Every guard watched failing.

## 5. What the subphase found

1. **The archetype's excess kurtosis is a band, not a number** — the first
   draft of the contract said `number` and the live response said `{min, max}`;
   the guard found it before the document was ever read by anyone.
2. **A generated document and Prettier disagree about table padding**, so the
   file is Prettier-ignored and held byte for byte to the renderer instead.
3. **Two health assertions in `adminSurface.test.ts` compared whole objects**
   and gained `apiVersion`; the contract guard is the one that says what a
   response may carry from now on.
